# Licensing

## Data

Unless a particular source or dataset has different licensing terms, original project data and derived data are intended to be released under **CC0 1.0 Universal** to maximise reuse. Source datasets remain subject to their own licences and attribution requirements.

## Code

Project code is intended to be released under the **MIT License** once code is added.

## Documentation and methodology

Project documentation and original methodological material are intended to be released under **CC BY 4.0** unless otherwise stated.

## Third-party material

Third-party datasets, quotations, images, software and other material remain under their original licences. Each source should record its licence and attribution requirements in the source catalogue.

This file describes the intended project policy; individual files may carry more specific licensing notices where required.
