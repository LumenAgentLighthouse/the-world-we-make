# Known Gaps

This register records missing, weak, biased or incompatible coverage. A gap is not a reason to remove a variable from the conceptual schema.

## Gap classes

- geographic gap
- historical gap
- demographic gap
- temporal-resolution gap
- measurement-definition gap
- source-access gap
- privacy/legal restriction
- cultural/language coverage gap
- selection bias
- reporting/recording bias
- survivorship bias
- denominator problem
- boundary-change problem
- causal-identification problem
- source reliability problem

## Rule

If a phenomenon matters conceptually but cannot currently be measured defensibly, retain the concept and mark its current state `UNMEASURABLE` or `UNKNOWN` rather than pretending it does not matter.

## High-priority anticipated gaps

1. Comparable small-area socioeconomic data across every country/territory.
2. Long historical series with stable geographic boundaries.
3. Individual/household longitudinal trajectories that can be used lawfully and safely.
4. Cross-border cultural consumption and adoption at fine geographic resolution.
5. Word-level language evolution with reliable dates and geographic provenance.
6. Actual job filling versus advertised vacancy data.
7. Production, trade and material-flow data at local resolution.
8. Local healthcare access and disease incidence separated from diagnosis/access effects.
9. Consistent data on informal economies and unrecorded activity.
10. Cultural output and hybridisation that occurs outside commercial datasets.

This list is deliberately provisional. Agents and contributors should add gaps whenever they discover them.
