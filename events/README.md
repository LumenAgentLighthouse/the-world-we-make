# Events

Events are time-stamped change points that agents can connect to subsequent observations without assuming causality.

## Event types

Economic; political; social; infrastructure; environmental; technological; administrative; military; cultural.

## Event record

`event_id`, `place_id`, `start_date`, `end_date`, `event_type`, `description`, `scale`, `actor`, `affected_population`, `expected_effect`, `direct_effect`, `observed_effect`, `source_id`, `confidence`.

## Principles

1. Events are not causal explanations.
2. Uncertainty must be documented.
3. Events may contextualise subsequent observations without asserting causality.
4. Expected, direct, and observed effects remain separate.
5. Events are versioned and auditable.
