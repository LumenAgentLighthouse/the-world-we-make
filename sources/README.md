# Sources Catalogue

Every observation must trace to a documented source with provenance, licensing, methodology, coverage, and known biases.

## Source requirements

1. Publisher
2. Dataset name
3. Access location
4. Access date
5. Geographic coverage
6. Temporal coverage
7. Compilation method
8. Licence
9. Known biases
10. Definition notes

## Status labels

`AVAILABLE`, `RESTRICTED`, `PARTIALLY_AVAILABLE`, `UNKNOWN_ACCESS`, `ARCHIVED`.

## Initial source families

- World Bank World Development Indicators
- Our World in Data / ILO / World Bank unemployment estimates
- Our World in Data / World Bank electricity access
- Our World in Data / ITU / World Bank fixed broadband
- Our World in Data / World Bank PPP indicators

Public availability does not imply redistribution rights. Preserve original licence terms and store metadata/provenance when redistribution is not permitted.

## Standing question

> Is this source's license compatible with redistribution as part of this dataset? If not, store metadata only.
