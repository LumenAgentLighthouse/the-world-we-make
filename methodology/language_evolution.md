# Language evolution and etymology

Language should be represented as a changing network rather than a static list of words.

## What to capture

For each lexical observation, preserve where possible:

- language code
- word/lemma and historical forms
- source language
- ancestor language
- reconstructed vs attested status
- inheritance, borrowing, derivation, calque or semantic-loan relation
- earliest known attestation
- dated intermediate forms
- semantic changes
- phonological/form changes
- cognates in related languages
- geographic location and dialect where known
- source dictionary/database
- source confidence and disagreement between sources

## Important distinction

A reconstructed proto-form is not an attested historical word. Mark reconstructed forms explicitly, normally with an asterisk where the source convention requires it. Wiktionary's etymology guidance makes this distinction explicit.

## Multilingual strategy

Do not build an English-centric language layer. Use source families appropriate to each language and connect them through language-family, borrowing and cognate relationships.

Initial source families include:

- Online Etymology Dictionary — English
- CNRTL/TLFi — French
- DWDS / Etymologisches Wörterbuch des Deutschen — German
- Treccani — Italian
- Wiktionary — multilingual comparative layer

Future expansion should include Spanish, Portuguese, Dutch, Swedish, Danish, Norwegian, Icelandic, Welsh, Irish, Scottish Gaelic, Scots, Russian, Ukrainian, Polish, Czech, Slovak, Lithuanian, Latvian, Greek, Arabic, Persian, Hebrew, Turkish, Hindi, Bengali, Urdu, Sanskrit, Tamil, Chinese, Japanese, Korean, Vietnamese, Indonesian, Malay, Swahili and other languages represented in the wider project.

## Analytical uses

This layer can connect with:

- migration and population movement
- trade routes
- conquest and political boundaries
- religious transmission
- technological adoption
- food and agricultural exchange
- colonial contact
- education and literacy
- media and cultural production
- scientific terminology
- urbanisation
- identity and group formation

A borrowing relationship should never automatically be interpreted as evidence of direct migration. It may arise through trade, prestige, bilingual contact, administration, religion, literature, media or another intermediary language.

## Evidence hierarchy

Prefer specialist historical dictionaries and scholarly resources where available. Use multilingual community resources such as Wiktionary as a broad discovery and relationship layer, while retaining source-level confidence and disagreements instead of silently resolving them.
