# Decision: Add Paired Distinction Variables

## Date
2026-09-05

## Decision type
Schema / variable addition

## Decision
Add paired distinction variables for employment, housing, crime, and health because the project's own measurement rules require them to remain separate where possible.

## Rationale
- Improves semantic integrity.
- Enables agents to distinguish related but different measures.
- Reduces proxy substitution and spurious correlations.
- Preserves the project's open-ended discovery objective.

## Changes
- Added employment, housing, crime, and health variables to the variable catalogues.
- Added observations where defensible data existed.
- Expanded the gap register and geographic coverage.
- Added provenance documentation and agent audit records.

## Reversibility
Future consolidation must preserve the audit trail and this decision record.
