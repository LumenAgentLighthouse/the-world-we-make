# Decisions

This directory records architectural, methodological, governance, and data decisions with provenance and reversibility.

## Decision record

Each decision should include: ID, date, type, decision, context, rationale, alternatives considered, changes made, version, reversibility, and review status.

## Categories

- Schema
- Methodology
- Governance
- Data
- Architecture

Rejected ideas remain documented rather than silently disappearing.

## Standing question

> Are we making decisions that lock us into a hypothesis rather than keeping the dataset open to discovery?
